# M06｜前端体验

负责人：前端；协作：设计；任务F01—F03；服务于R01—R15。

必读 [需求与体验](../01_项目手册/04_产品需求与验收.md)、[API](../02_开发手册/02_API契约.md)、全局约束与状态机。只按需阅读调用模块的输入输出，不加载扫描算法和部署细节。

## 页面责任表

| 页面 | 主要任务 | 必须包含的异常状态 |
|---|---|---|
| 内部登录/邀请 | 验证邮箱、接受邀请 | 未获授权、失效、限流、邮箱不匹配 |
| 项目列表 | 新建、搜索、筛选 | 空列表、无结果、只读、额度不足 |
| 项目详情 | 当前交付与历史 | 草稿与发布版并存、已撤回、已归档 |
| 草稿编辑 | 文件顺序、说明、上传、发布 | 排队、扫描失败、超限、冲突、断网 |
| 发布/分享 | 填指定邮箱、展示一次性链接 | 链接丢失提示显式重发；提醒旧链接会失效 |
| 客户验证 | 输入邮箱与验证码 | 链接不可用、验证码过期、重发倒计时 |
| 客户审阅 | 图片查看、PDF下载、文字意见 | 加载失败、授权切换、终态只读 |
| 决定与记录 | 需要修改/确认、结果、打印 | 网络未知结果、重复提交、版本变化 |
| 团队设置 | 成员、额度、到期、删除 | 非Owner无操作、删除期限与恢复 |

## 交互准则

所有写操作都显示服务端确认状态；提交决定时不得用乐观更新直接显示“已确认”。网络中断显示“正在核实提交结果”，查询原决定后再让用户重试。表单文本在短暂失败时保留，但客户评论与密钥不持久化到长期浏览器存储。

轮询文件状态采用递增间隔并在页面不可见时暂停；完成或离开页面停止。只重试可安全重试的读请求，写请求遵守幂等和冲突处理；409不自动套用新revision。

所有文件展示名称转义，评论使用纯文本组件。错误码映射到可行动的中文说明；不要把数据库异常或栈直接显示给用户。每个页面都有加载、空态、错误、无权限、只读状态。

## 客户端决策文案

主按钮“确认本版”，次按钮“需要修改”；弹窗明确本轮结束、后续变更需新版本；不可使用“签署”“法律存证”等词。下载PDF旁提示本轮需下载审阅。图片缩略图只代表预览，提供原件下载入口。

## 验收与交付

桌面及360px移动宽度、键盘焦点、表单错误读屏关联、慢网断网、微信内置浏览器、刷新后状态、双窗口授权切换、长文件名、多页打印。设计规范包含字号、间距、颜色与禁用态，不需要先建设庞大组件库。

交付页面清单、组件说明、端点映射、浏览器证据、模拟与真实联调差异清单。未接真实服务的页面标为模拟完成，不能声称业务已完成。
