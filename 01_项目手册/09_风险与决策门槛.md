# 风险与决策门槛

概率与影响采用高/中/低的规划判断，每周更新；此表不代表风险已经发生。

| 风险 | 概率/影响 | 先行信号 | 应对与责任 |
|---|---|---|---|
| 替代方案已足够 | 高/高 | 访谈无具体问题、试点不复用 | 产品按 GATE-A 停止或缩小人群 |
| 客户拒绝邮箱验证 | 中/高 | 流程试演放弃率超过20% | 产品重审用户选择，不直接追加短信开发 |
| 首版太窄 | 中/高 | 无标注/视频就拒绝试点 | 产品判断是否转向；新增范围重新估算 |
| 版本和确认错配 | 中/高 | 并发测试出现旧版被当作当前确认 | 技术实施项目锁、唯一决定和快照 |
| 客户文件泄露 | 中/高 | 任一越权或存储公开读 | 暂停外部访问、定位、修复并复测全部链路 |
| 邮件到达率不足 | 中/高 | 目标邮箱多次不能及时收码 | 运维验证域名信誉与供应商；无法达标不试点 |
| 扫描延迟或误判 | 中/中 | 正常文件超时和失败率高 | 文件模块限制资源、显示状态、人工分析，不绕过扫描 |
| 后端关键路径拥堵 | 高/中 | 连续两周未完成目标流程 | 项目经理动用缓冲、推迟上线、保持范围 |
| 上线手续延迟 | 中/高 | 主体/域名/接入要求不清楚 | 运营在 W1 启动核验，研发完成后等门槛 |
| 成本超预算 | 中/中 | 存储和出站连续上升 | 运营看团队级用量；配额/价格需正式变更 |
| 记录被误当电子签章 | 中/高 | 用户认为可代替合同签署 | 产品修正文案和客户教育，必要时放弃该定位 |
| 人员中断 | 中/中 | 关键知识只在聊天 | 每任务交接，定期恢复演练，保留文档权威 |

## 不能放行的情形

跨空间访问、撤销后仍可形成新决定、已发布文件可被覆盖、备份恢复失败、未扫描文件可下载、P0 未完成、运营主体/接入条件未落实。任何一项存在即不扩大试点；数据泄露时停止相关入口。

## 决策门槛

GATE-A 看问题和流程验证；GATE-B 看核心链路及事务正确性；GATE-C 看质量、恢复和上线前置；GATE-D 看真实复用与付款。各门槛要求和计数引用相应手册，不用项目进度百分比替代。

未达门槛允许一次明确的修正实验：写出问题、改变的变量、最长两周观察期和通过线。仍失败就停止扩张或转向，不无限追加“再做一个功能试试”。停止项目也应交付研究记录、用户数据处置计划和费用结清记录。
