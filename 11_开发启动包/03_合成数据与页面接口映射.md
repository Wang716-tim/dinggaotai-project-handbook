## 原型语义页面与接口

路径均位于 `/api/v1`。此表按页面语义关联[可点击纸面原型](../09_产品原型/定稿台_可点击纸面原型.pdf)中的实际 PDF 页码。模拟邮箱、复制和下载反馈是原型辅助页面。接口字段、响应形状和错误语义参见[请求响应样例](02_请求响应与错误样例.md)及[公共契约](../02_开发手册/02_API契约.md)。

| 页面与原型位置 | 主要接口与成功态 | 异常态与恢复 |
|---|---|---|
| 内部登录和邀请（实现检查） | `GET /auth/csrf`。`POST /auth/challenges`、`POST /auth/verify`。`GET /me`。受邀用户调用 `POST /invitations/accept` | 统一资格提示、过期验证码、限流、邀请邮箱不匹配。待接受身份仅见自身状态。只读时拒绝接受邀请。 |
| 项目列表（第 2 页） | `GET /projects` 读取、查询或筛选列表。`POST /projects` 创建 P | 空列表、查询无结果、游标或输入错误、只读、额度不足。网络后恢复从实际列表确认。 |
| 项目详情与历史（第 13、25 页） | `GET /projects/{id}` 和 `GET /projects/{id}/versions` 显示当前版和历史。`POST /projects/{id}/versions` 创建新草稿 | V2 草稿与 V1 当前发布版并存。草稿冲突回到现有草稿。可见归档、撤回、跨空间不可读。禁止把历史确认显示为当前版已确认。 |
| 草稿编辑与上传（第 3、4、14、15、29 页） | `GET/PATCH /versions/{id}`、`POST /versions/{id}/uploads`、`PUT /uploads/{id}/content`、`GET /uploads/{id}`、`GET /assets/{id}`、`POST /assets/{id}/retry`、`DELETE /assets/{id}` | 队列、扫描失败、大小或额度超限、过期接收、断网和 revision 冲突。先读 `state`、`received_complete` 判定完整接收。已完整接收的原件只等待处理，未完整接收则等预留释放后重新申请。 |
| 发布与分享（第 4、5、15、16、34 页） | `POST /versions/{id}/publish` 返回一次性链接。`POST /versions/{id}/shares` 显式重发。`DELETE /shares/{id}` 撤销。`POST /versions/{id}/withdraw` 撤回未决审阅 | 未就绪或冲突时保持原状态，引导刷新。响应丢失后按原键恢复，确需链接再显式重发。重发说明旧链接及旧会话失效。 |
| 客户验证（第 6—8、17—19、31 页） | `GET /auth/csrf` 同源引导。`POST /review/challenges`、`POST /review/verify`。验证成功返回 `data={version}` 并进入当前授权版 | 接收验证码、中性提示、不匹配邮箱、链接无效、过期和重发倒计时。验证前界面没有项目名称或文件名。 |
| 客户审阅与反馈（第 9、10、20、21、33 页） | `GET /review/version` 读 `data={version,decision}`、`GET/POST /review/comments`、`POST /review/assets/{id}/download`。V1 客户意见与内部公开回复按轮展示 | 下载失败时在仍有权限的前提下重新签发。短时 URL 失效不复用。授权切换或旧版拒绝时回到对应入口。终态只读。 |
| 客户决定与结果（第 11、12、22—24、30 页） | `POST /review/decisions` 提交两种决定。`GET /review/version` 核实。`GET /review/receipt` 读取本轮记录 | 缺修改说明、未确认勾选、重复决定、网络未知结果、授权过期。提交期间保留原请求内容和键。响应不明时先读当前轮，有决定再读记录，仍不确定且授权有效才用原键和原请求重试。 |
| 内部反馈与记录（第 13、25—28、33 页） | `GET/POST /versions/{id}/comments`。`GET /versions/{id}/receipt`。`GET /versions/{id}/receipt/export`。打印与 JSON 保持快照一致 | 已封存反馈不能新增。无记录时显示未决定。长文件名、多页打印、归档保留的历史与删除受限状态。 |
| 团队设置和通知（空间只读见第 32 页，其余按实现检查） | `GET /me`、`GET /members`、`POST /invitations`、`DELETE /members/{id}`。项目归档、恢复、删除和撤回删除使用原项目端点。`GET /notifications`、`POST /notifications/{id}/read` | 非 Owner 隐藏相应管理操作并保留服务端拒绝。到期动作按权限表。删除显示 7 天可撤回窗口，恢复后旧链接仍失效。本人通知读标记按状态表。 |

页面检查需覆盖加载、空态、错误、无权限和只读，以及 360px 移动宽度、键盘焦点、错误读屏、慢网、双窗口授权切换与打印。查看固定记录时说明邮箱验证表示当时可接收该邮箱验证码，记录用于业务反馈和确认。真实浏览器联调和相关产品用例须另行记录构建与环境证据。
