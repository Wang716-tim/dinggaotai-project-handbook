# 数据模型

所有字段为设计定义，不是数据库建表代码。ID 使用 UUID；时间使用带时区 UTC；业务表默认含 id、created_at、updated_at 和 workspace_id。不可变记录仅有创建时间，撤销／清理通过独立字段或事件表达。

## 身份与配额

| 实体 | 关键字段 | 约束和生命周期 |
|---|---|---|
| User | email_normalized、display_name、status | 规范化邮箱唯一；不混合外部客户身份 |
| Workspace | name、service_state、expires_at、storage_used_bytes、storage_reserved_bytes、quota_bytes、revision | service_state 为 ACTIVE/READ_ONLY/SUSPENDED/DELETION_PENDING；到期转只读，冻结拒绝外部访问 |
| Membership | user_id、role、status | 每 user 首版仅一个有效空间；每空间仅一名 Owner；移除不删除历史审计 |
| Invitation | email、role、expires_at、status、token_digest | 待接受邀请计入席位；7 天失效；邀请只能产生 Editor |
| OtpChallenge | purpose、subject_digest、code_digest、expires_at、attempts、consumed_at、grant_id 可空 | 管理登录与客户访问用途隔离；重发作废旧码；验证码不明文保存 |
| InternalSession / GuestSession | user_id 或 grant_id、secret_digest、expires_at、last_seen_at、revoked_at | 分开凭据和访问链路；客户记录验证邮箱摘要与验证时间 |

邮箱规范：去首尾空格、域名小写；本项目账号匹配按完整邮箱小写处理，不做点号或加号折叠。若遇到依赖本地部分大小写的特殊邮箱，在试点准入时说明不支持。邮箱传输加密、存储访问受限，日志只存脱敏值；系统运维备份加密。

## 项目与文件

| 实体 | 关键字段 | 约束 |
|---|---|---|
| Project | title、status、current_version_id、next_version_number、revision、deletion_requested_at、previous_status | 空间内标题可重复；当前指针必须指向本项目已发布版本 |
| Version | project_id、number、status、title、description、reviewer_email、published_at、manifest_digest、revision、deleted_at | project+number 唯一；每项目最多一个未删除DRAFT；发布字段冻结 |
| Asset | version_id、display_name、position、kind、bytes、sha256、object_key、preview_key、status、failure_code | object_key 唯一不可覆盖；version+position 唯一；published 后禁止更新内容 |
| UploadReservation | version_id、asset_id、declared_bytes、reserved_bytes、receive_expires_at、state、processing_job_id | state为RECEIVING/PROCESSING/SETTLED/CANCELLED；15分钟只限制接收，处理中预算不能被接收过期任务释放 |
| ShareGrant | version_id、token_digest、reviewer_email、expires_at、revoked_at、created_by | 每版本最多一个未撤销授权；重发先撤销旧授权；不能变更版本指定邮箱 |

文件大小含原件及衍生预览。预留策略：原件声明大小 + 每图片 2 MiB 衍生上限；PDF 无预览预留。预览必须在上限内；上传实际大小超过声明或全局上限即终止。完整接收时在同一事务内结算原件、将余下衍生预算转为PROCESSING、绑定任务并写outbox。即使扫描晚于15分钟，处理中预留仍有效；接收过期处理只处理未完成接收的记录。

ProcessingAttempt记录job_id、lease_generation、temp_object_key、reserved_bytes、actual_bytes、state和cleanup_job_id；每次执行代际独立，任务接管不能重用仍可能被旧代占用的预算。对象写入前先预留该代预算，额度不足则等待清理旧代，不先写入再补账。旧代失租不等于停止外部写入；需终止/确认其写入完成并清理对象后才释放预算。输出先在受限本地临时盘生成，最终引用与账目只在有效代际事务内发布；未引用对象仍有台账和清理任务。

ObjectWriteAttempt 逐次持久登记写入能力、截止时间、请求结果和终结证据；ProcessingAttempt 可进入 WAITING_CLEANUP/BLOCKED_CLEANUP。独立回收与释放条件唯一遵循 [文件写入与回收协议](07_文件写入与回收协议.md)，不能将客户端超时或 HEAD 不存在等同于写入已经停止。

## 审阅与记录

| 实体 | 关键字段 | 约束 |
|---|---|---|
| Comment | version_id、asset_id 可空、author_kind、author_id、body、created_at | 附件必须属于同版本；仅 IN_REVIEW 可新增；不提供编辑删除接口，违法内容由受控处置记录屏蔽 |
| Decision | version_id、outcome、message、guest_session_id、verified_email、decided_at | version_id 唯一；outcome 为 APPROVED/CHANGES_REQUESTED；创建后不改写 |
| Receipt | decision_id、schema_version、project_snapshot、version_snapshot、files_snapshot、comments_snapshot、identity_method、snapshot_digest | decision_id 唯一；快照不依赖后来项目改名或账号删除；标识为业务记录 |
| AuditEvent | actor_kind、actor_id、action、target_kind、target_id、request_id、safe_metadata | 业务角色只能追加；不得存文件正文、验证码或分享密钥 |
| DeletionTombstone | target_id、requested_at、purged_at、backup_expiry_at、reason | 不含原文件内容；恢复备份前应用删除清单 |

Receipt 文件项包括文件 ID、当时显示名、顺序、字节数、MIME、原件 SHA-256；身份项包括验证邮箱、验证时刻、决定时刻、身份说明及确认文案版本。快照可用受版本控制的 JSON 表示，序列化规范和摘要算法在 T01 固定；摘要用于一致性检查，不等于外部可信存证。

## 任务与幂等

| 实体 | 字段 | 约束 |
|---|---|---|
| OutboxJob | job_type、dedupe_key、payload_ref、status、attempts、available_at、lease_until、lease_generation、lease_owner、last_error_code | dedupe_key唯一；每次领取递增代际，续租/提交校验代际与归属；payload只存引用 |
| DeliveryEnvelope | purpose、secret_ciphertext、expires_at、consumed_at、invitation_id或challenge_id | OTP和邀请的短期加密投递载体，任务仅持secret_ref；发送成功/失效即清理 |
| Notification | recipient_membership_id、event_id、read_at | event+recipient 唯一；成员移除后不继续投递 |
| IdempotencyRecord | actor_scope、route、key、request_digest、result_ref、expires_at | actor+route+key 唯一；同 key 不同请求拒绝；只存无密钥结果引用 |

幂等记录保留 24 小时，业务唯一约束永久生效。决定重放返回原结果；发布重放返回已发布版本与 share_id，不再返回原始分享密钥。密钥丢失时显式重发分享，不能把原密钥明文存入幂等缓存。

幂等键竞争占位、请求摘要、业务写入、result_ref及相关outbox在同一数据库事务提交。actor_scope为可信空间ID与成员ID或分享授权ID，路由包括目标资源ID；相同键并发者等待首个事务后读取同一结果，同键不同内容返回409。重放先复核当前身份和对象权限，缓存不能复活失效授权。

项目增加deletion_generation，删除请求、撤回删除均递增；PROJECT_PURGE与对象清理任务绑定该代际。普通附件删除不允许碰发布内容；宽限期满、请求未撤回且代际匹配的项目级清理可处理该项目全部版本及记录。更新删除凭据及释放占用以实际清理成功为准。

## 索引与一致性

索引至少覆盖：项目 workspace/status/created_at/id；版本 project/number；评论 version/created_at/id；任务 status/available_at；分享 token_digest；成员 user/status；审计 workspace/created_at。关系必须验证空间一致，关键关联以包含 workspace_id 的唯一键和复合外键或等效约束保证，不仅依靠调用者自觉。

业务服务读取必须先限定租户。事务使用数据库实际约束和锁来处理并发；开发测试使用真实 PostgreSQL，不以 SQLite 通过代替。快照和审计的保留受隐私删除规则约束，不能以“不可变”拒绝合法删除。
