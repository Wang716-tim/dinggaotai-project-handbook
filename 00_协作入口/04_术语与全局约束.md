# 术语与全局约束

状态：v1.5规划基线；G01—G16及数值限制沿用v1.3。本轮总负责人兼产品/技术职责，按用户授权完成一致性修订；记录在06项目总控。这里是全局规则唯一权威，后续跨角色修改需同步产品与技术负责人。

## 术语

工作空间 Workspace 是一个付费／试点团队及数据隔离边界；成员 Membership 是内部账号与空间的关系；项目 Project 是一次客户交付；版本 Version 是一次完整交付文件清单；附件 Asset 是该版本的一个文件；分享授权 ShareGrant 把一个版本授权给一个指定邮箱；客户会话 GuestSession 是验证该邮箱后的有限访问凭据；决定 Decision 是“确认”或“需要修改”；记录 Receipt 是决定时的固定内容快照；事件 AuditEvent 是系统留痕，不是司法存证。

## 固定规则

| ID | 规则 |
|---|---|
| G01 | 首版一个内部账号只加入一个工作空间。角色为 Owner、Editor；两者均可查看该空间全部项目；仅 Owner 管理成员、配额和删除。客户不是内部成员。 |
| G02 | 试点每空间最多 5 名内部成员、20 个未归档项目、10 GiB 原件与衍生文件总量；归档仍占存储。所有额度服务端强制执行。 |
| G03 | 文件类型仅 JPEG、PNG、PDF；单文件最多 25 MiB；每版本最多 20 个文件，至少 1 个 READY 文件才能发布。图片像素总量最多 40 MP。1 MiB = 1,048,576 字节。 |
| G04 | 图片提供安全重编码预览及原件下载；PDF 仅下载，不承诺浏览器内预览。扫描或校验未成功不得发布或下载原件。 |
| G05 | 每项目最多一个草稿；每版本发布后文件、标题、说明、顺序及确认人不可修改。修改必须新建完整版本；首版不做跨版本文件去重或附件复用。 |
| G06 | 一个发布版本只有一个指定邮箱确认人；先验证邮箱，再读文件、评论和决定。邮箱控制权不等于实名身份或客户公司授权。 |
| G07 | 一个版本最多一个最终决定。确认与需要修改均封存该轮反馈；后续修改另开版本。Owner 与 Editor 不能代替客户决定。 |
| G08 | 新草稿不影响当前发布版；发布新版本时撤回上一轮仍在审阅的版本，撤销旧版全部分享和客户会话。历史决定保留，不能被新决定覆盖。 |
| G09 | 分享密钥至少 256 位随机熵，仅保存摘要；默认 7 天有效、可选 1—30 天；到期不自动改变版本状态。撤销后旧会话失效，同版可重发但不可换确认邮箱。 |
| G10 | 邮箱验证码 6 位、10 分钟有效、最多失败 5 次；重发间隔 60 秒，单邮箱每小时 5 次、单 IP 每小时 20 次；新码作废旧码。错误响应不暴露邮箱是否存在。 |
| G11 | 客户会话最长 8 小时且不超过分享有效期；内部会话最长 7 天、连续 24 小时不活动失效。下载签名有效 60 秒；撤销不能召回已下载文件或已签发且未过期链接。 |
| G12 | 所有业务对象携带 workspace_id；服务端从可信会话解析空间，不接受请求体自行声明租户身份。外部请求另校验 grant → version → project 链路。 |
| G13 | 状态变更、决定、记录、审计、通知待发事件及幂等结果引用须按相关事务边界一致提交；同幂等键竞争不能产生各自已提交的业务对象；邮件失败不能回滚已成功的决定。 |
| G14 | 内部时间存 UTC，界面默认 Asia/Shanghai 并明确显示时区；对象标识使用不可猜测 ID；序号仅用于展示。 |
| G15 | 删除请求先撤销访问并进入 7 天可撤回期；活动数据和对象最迟在请求后 30 天清理；每份备份从生成起最多保留 35 天，因此残留备份最迟可在请求后 65 天过期。删除清单保证恢复时不会重新开放已删除内容。法定保留例外需评估和记录。 |
| G16 | 首版不具备电子签章、公证、可信时间戳、绝对不可篡改或版权确权能力。导出是业务记录；营销和界面不得宣称其具有这些能力。 |

## 文本与列表限制

项目标题 1—120 字符；版本说明最多 2,000 字符；文件显示名最多 180 字符；单条评论 1—2,000 字符且只允许纯文本；需要修改的决定必须有 1—2,000 字符说明；确认可有不超过 2,000 字符备注。所有长度按 Unicode 字符计数，前后端使用同一边界样例。列表默认每页 20，最大 100；按创建时间和 ID 稳定游标排序。

上述数字是为了首版可交付而作出的产品决策，不是市场调查结论。套餐变化必须同时检查并发配额、成本和验收用例。
