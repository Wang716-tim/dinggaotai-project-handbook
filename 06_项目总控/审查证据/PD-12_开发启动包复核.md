## 字段及行为复核

| 条目 | 核对结果 |
|---|---|
| 响应包络及空值 | 成功用 `data`、`request_id`，分页额外带 `next_cursor`，无结果为空数组；失败用 `error.code`、`error.message`、可选 `error.fields` 和本次 `request_id`；204 无响应体。Project 当前发布指针、Version 发布时间、Asset 失败码、评论附件和分页结束采用公共空值规则。3 段完整 JSON 均可解析。 |
| 文件接收与可访问性 | 预留返回 `upload_id`、`asset_id`、`expires_at`。接收后返回 `PENDING_SCAN` 的 Asset，状态查询用 `state`、`asset_id`、`received_complete`、`expires_at`。完整接收后以状态查询恢复，未完整接收需等待旧预留释放。JPEG/PNG 预览、PDF 仅下载，所有发布附件均需 READY，下载签名 60 秒。 |
| 发布、验证与授权 | 发布和重发首响应含一次性链接，成功重放 200 只给契约允许的数据。发布还包含原版 `version`，两种重放都不含原链接。客户验证返回授权 `version`，审阅版本读返回 `version` 和 `decision`。新轮发布撤销旧授权与会话，仍保留已完成的旧决定及历史记录。 |
| 评论和决定 | Comment 的 `asset_id` 可空且须属于本轮，角色为 `MEMBER/GUEST`，无内部私密作者 ID。确认要求 `acknowledged=true` 及 `REVIEW_CONFIRM_V1`。需要修改要求说明，带 `false` 及 `null`。新键遇既有决定 409 并按有权限的读接口恢复。未知响应先查实际状态，继续重试须当前授权有效并沿用原键和请求。 |
| 固定记录 | Receipt 含 `id`、`decision_id`、整数 `schema_version`、项目/版本/文件/评论快照、身份方法、`outcome`、`message` 和 `snapshot_digest`。11 样例的 `project_snapshot.workspace_name` 原先未列在公共 API，现已回填并和数据模型及 M05 同步。读取 `data`、导出的无包络 JSON 及打印共用原快照。摘要规范和真实样本留 T01 冻结。 |
| 权限与冲突 | 样例保留客户和内部会话隔离、版本错配、撤销、跨空间 404、只读限制、CSRF 与 Origin 检查。只有有效权限下的同键同内容可重放。本次响应有新的 `request_id`，成功后原 revision 可随原请求重放。错误码仍待冻结的细分和触发重叠优先级有登记。 |

契约另和 [M05 记录责任](../../03_模块工作包/M05_确认与记录.md)、[跨模块测试场景](../../02_开发手册/06_跨模块场景样例.md)核对。启动包 02、03 的 69 处显式接口路径引用可在公共 API 中找到。启动包 85 个本地链接均有目标，其中 20 个带标题锚点且有效。

## 合成场景和启动依赖

- 28 个实体 UUID 均可解析并且互异。P、V1/V2、A11/A12/A21/A22、S1/S2/S2R、C1/C2、G1/G2、M1、D1/D2 与 R1/R2 跨样例对应。两轮确认邮箱、图片/PDF 显示名、类型和字节数一致。附带文件摘要仅作占位。
- 12 行主时间线从项目创建到两轮版本、决定和历史打印。10 个期限符合四次 15 分钟接收、两次 7 天分享、两次 10 分钟验证码及两次最长 8 小时客户会话。V1 意见为将 7 月 12 日改为 7 月 19 日。V2 使用两份新附件并独立确认，V1 评论不迁移且历史决定保留。两轮时间线和状态、权限、主要文件元数据一致。
- 16 张首批任务卡均含责任范围、输入依赖、可检查输出和回退交接。GATE-A 先于 T01，T01-C 与 T01-S 各有证据。B06-QUEUE 提供领取与去重基础，B03 的实际写入等待 TR01/TR02 放行；B02-CORE 可先依 READY 契约准备。B04-GRANT 用 B02-CORE 锁接口供 B02-PUBLISH 调用，完整客户入口与反馈随后接通，闭合发布与授权依赖。Q01 准备与随实现首测，Q02 和 O01 提供实际验收与演练，O02-PRE 通过及公开前置齐备后，O02-RELEASE 仍需用户具体发布确认。
- 77 人日落在首批卡，B06 通知后续 2 人日，其余原任务 39 人日，合计 118 人日。14 人日风险缓冲继续未分配。文件实验、恢复演练、通知消费和后续验收均在原任务内跟进。
