# 交接单模板

交接标题：任务ID + 模块 + 截止时间。接收者应能凭此文档继续，不需要翻全部聊天。

## 必填内容

1. **目标和当前状态**：原任务是什么，已完成到哪一步；未完成直接标明。
2. **实际变更**：逐项列交付物与可打开的位置；区分方案、模拟、实现和已验证。
3. **契约基线**：使用的全局、数据、API和状态机版本；列出获准变更编号。
4. **验证证据**：实际执行项目、环境、结果、失败或未运行项目；不写笼统“全部正常”。
5. **未解决问题**：影响、复现条件、当前判断、下一步、责任人。
6. **下一位成员最小输入包**：任务卡、本模块、必要契约章节和本交接单。
7. **下一步首个动作**：具体可执行且与任务范围一致。

## 不应交接的内容

不复制整段聊天、未经验证的结论、生产凭据、真实客户文件和无关模块方案。若需提供敏感证据，使用受控工单或访问授权，不放进公共文档。
