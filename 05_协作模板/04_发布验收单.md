# 发布验收单模板

当前状态：未执行、未批准发布。实施团队填写实际证据后使用。

| 项目 | 要填写的结果与证据 |
|---|---|
| 发布标识 | 版本、镜像摘要、提交标识、目标环境、执行窗口 |
| 范围与契约 | 本次需求、API/数据库变化、文档版本 |
| 需求验收 | R01—R16各项结果；未完成项及其影响 |
| 测试 | A01—A32及P0条款子项结果、浏览器和压测报告 |
| 缺陷 | S0/S1是否清零；S2接受人、替代路径和期限 |
| 恢复 | 最近完整备份点、实测整体RPO/RTO、恢复和回滚证据 |
| 数据安全 | 桶私有、授权撤销、日志脱敏、生产密钥管理验证 |
| 上线前置 | 主体、域名、接入、隐私说明、邮件及联系渠道 |
| 迁移与回滚 | O02-PRE证据、顺序、兼容、停写窗口、首次停入口或后续版本回退、执行人 |
| 业务观察 | 内部合成项目结果、试点批次、下一次观察时间 |
| 值班 | 主值班、备份联系人、告警渠道和响应安排 |
| 四方结论 | 产品、技术、测试、发布负责人分别给出通过/不通过及日期 |

任何字段“未知”都必须给出处理人；阻断项不能由空白默认通过。事后填写发布成功、异常和实际回滚情况，保留证据。
